# Support

Use GitHub Discussions for questions, implementation ideas, and shared
experience when Discussions are enabled. Use an issue only for a reproducible
bug or a concrete feature proposal.

Attractor's open-source repositories are maintained on a best-effort basis.
They do not include service-level guarantees or private implementation
consulting. Commercial enquiries can be sent through
[attractor.fi](https://attractor.fi/).

Never report a vulnerability in a public issue. Follow
[`SECURITY.md`](SECURITY.md).
