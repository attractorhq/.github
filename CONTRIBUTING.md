# Contributing

Thank you for helping make Attractor's open-source projects more useful.

## Before you begin

For a question or usage problem, use the support channel documented in the
repository. For a security concern, follow [`SECURITY.md`](SECURITY.md) and do
not open a public issue.

For a code or documentation change:

1. Check existing issues and discussions.
2. Open an issue before starting a large or behavior-changing contribution.
3. Keep the change focused and include tests or examples where appropriate.
4. Run the repository's documented checks.
5. Explain the problem, approach, and validation in the pull request.

By participating, you agree to follow our
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). Contributions are accepted under
the repository's Apache-2.0 license.
