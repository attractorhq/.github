# Attractor community health files

This special repository provides Attractor's organization profile and default
community health files for repositories that do not define their own.

- The public organization profile is in [`profile/README.md`](profile/README.md).
- The roadmap and success measures are in [`docs/ROADMAP.md`](docs/ROADMAP.md).
- Draft launch copy is in [`docs/LAUNCH.md`](docs/LAUNCH.md).
- The maintenance commitment is in
  [`docs/MAINTENANCE.md`](docs/MAINTENANCE.md).
