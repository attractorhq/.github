# Open-source roadmap

Attractor's first five public projects address the path from an AI prototype to
a production service. Three implementation-focused projects help teams ship;
two community learning resources help teams build shared judgement. Every
project is intentionally practical and provider-neutral.

## Release sequence

1. **production-ai-checklist** — an evidence-based checklist, stable JSON
   Schemas, templates, and a TypeScript CI validator.
2. **ai-evals-starter** — a minimal Python starter for offline evaluation of
   recorded AI outputs.
3. **rag-quality-workshop** — a self-paced TypeScript workshop built around a
   deliberately flawed support-search application.
4. **tips-for-building-ai** — an evergreen, cross-disciplinary field guide for
   making better AI product and delivery decisions.
5. **ai-failure-drills** — facilitator-ready tabletop exercises for rehearsing
   AI quality, security, reliability, data, and ownership failures.

Each project starts at `v0.1.0` after its clean-clone quick start and CI pass.

## First 90 days

We will use outcomes, not vanity traffic, to decide what to improve:

- 25 genuine stars for the flagship project.
- Five external forks across the portfolio.
- Three meaningful external issues or pull requests.
- One candidate or client conversation that references the work.

For the two learning resources, we will also look for evidence that teams use a
tip in a real decision or run a drill and create owned follow-up. Feedback may
change the order or scope of later improvements.
