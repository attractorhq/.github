# Maintenance commitment

Attractor reserves about two hours each month for this portfolio:

- 30 minutes for issue and pull-request triage.
- 30 minutes for link, dependency, and security updates.
- 60 minutes for one useful improvement.

Every repository is reviewed quarterly for stale AI guidance. If we can no
longer maintain a project, we will mark it clearly, explain the decision, and
archive it rather than imply active support.
